# 🚚 ЧеркасиRoute — Оптимізатор кур'єрських маршрутів м. Черкаси

> Сучасний веб-додаток для кур'єрів та водіїв доставки містом Черкаси. Допомагає розв'язати **задачу комівояжера (TSP)**: будує найкоротший логічний маршрут об'їзду списку адрес і відображає його на карті **OpenStreetMap**.

---

## ✨ Основні можливості

- 🗺️ **Інтерактивна карта OpenStreetMap (OSM)**: оригінальна детальна карта, що працює без блокувань та помилок 403.
- 🌙 **Нічна тема (Dark Mode)**: зручне перемикання світлої/темної теми для роботи за кермом у нічний час.
- ⚡ **Маршрутизація OSRM Trip API**: автоматичне сортування адрес для досягнення мінімального кілометражу та часу в дорозі.
- 📍 **Геокодування через OSM Nominatim**: автоматичне дописування «Черкаси, Україна» та захист від перевищення лімітів (затримка 1.1 сек + прогрес-бар).
- 🖱️ **Додавання адрес кліком по карті**: достатньо клікнути на карті Черкас, і адреса визначиться автоматично.
- 🏢 **Швидкі хаби**: кнопки для додавання популярних точок Черкас в 1 клік (ТРЦ Любава, Епіцентр, Центральний ринок, Дніпро-Плаза, Нова Пошта №1, Вокзал).
- 📱 **Мобільна оптимізація**: нижня навігаційна панель, адаптація під iPhone/Android, захист від авто-зуму.
- 🧭 **Плаваюча картка водія**: показує наступну зупинку, відстань, час та кнопку переходу в навігатор.
- 📦 **Чекліст доставок**: відмітка виконаних замовлень із лічильником прогресу.
- 💾 **Експорт**:
  - Відкриття всього багатоточкового маршруту в **Google Maps**;
  - Завантаження треку **`.gpx`** для навігаторів (OsmAnd, Garmin);
  - Копіювання текстового списку для месенджерів (Viber, Telegram);
  - Друк паперового маршрутного листа.

## 🛠️ Як завантажити та запустити на GitHub (Інструкція за 2 хвилини)

1. Перейдіть на [github.com/new](https://github.com/new) та увійдіть у свій акаунт GitHub.
2. Вкажіть назву репозиторію (наприклад, `cherkasy-route` або `maps`).
3. Виберіть тип **Public** (Публічний).
4. Натисніть кнопку **Create repository**.
5. На сторінці нового репозиторію натисніть посилання **«uploading an existing file»** (або просто перетягніть файли `index.html` та `README.md` у вікно браузера).
6. Натисніть зелену кнопку **Commit changes**.
7. У верхньому меню репозиторію відкрийте **Settings** (Налаштування) ⚙️ -> ліворуч виберіть пункт **Pages**.
8. У розділі **Build and deployment** під пунктом **Branch** виберіть гілку `main` (або `master`) та папку `/ (root)`, після чого натисніть **Save**.
9. Зачекайте 30–60 секунд, оновіть сторінку — вгорі з'явиться готове публічне посилання:
   👉 **`https://<ваш-логін>.github.io/<назва-репозиторію>/`**

## 💻 Локальний запуск

Просто двічі клікніть на файл `index.html` на вашому комп'ютері. Додаток повністю автономний і працює у будь-якому сучасному браузері без необхідності встановлювати додаткові програми чи сервери.
